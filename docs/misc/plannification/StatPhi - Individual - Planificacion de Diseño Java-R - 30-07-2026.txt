> Cambio .NET a Java:
	- Java se queda como núcleo de la aplicación.
	- Es probable que Java use una arquitectura Hexagonal o Clean + Pipes + Plug-in
		Clean Architecture o Hexagonal como arquitectura principal
		Talvez se use la arquitectura Vertical Slicing para organización de los servicios del motor de calculo en modulos específicos.
		Arquitectura de Tuberias o Filtros para combinar diferentes operaciones, posibilidad de combinar operaciones y resultados en un solo calculo.
		Arquitectura plug-in para integración de nuevos motores de calculo (opcional).

	- R se convierte en motor estadístico avanzado, por sus funciones integradas para este ámbito.
	- Java también es usado para un motor matemático avanzado y motor estadístico reducido, esto para reducir llamadas (latencia) y sobrecarga a R.

	- Crear o establecer niveles de operaciones, como la siguiente:
		Nivel 1 - Operaciones simples		-> Java
		Nivel 2 - Matemática computacional	-> Java
		Nivel 3 - Estadística especializada	-> R
	
	- Se debe convertir R en un servicio de calculo que reciba los datos y ejecute los calculos estadisticos (JAMAS llamar a R en operaciones sencillas)
	- Existe 2 formas en las que se podría comunicar Java con R:
		1. Se puede convertir a las funciones de R en una API web consumible por HTTP, usando la librería "plumber" de R.
			Java
			   │
			   │ HTTP / gRPC
			   v
			R Web Endpoint
			   │
			   v
			R Function
	
		2. Se puede convertir el código R en un paquete o librería, y, mediante las librerías "RCaller", "JRI" o "Rserve" (Cliente-Servidor) de Java, se podría llamar y ejecutar
		   las funciones de la librería de R creada.

		En Java se pueden usar interfaces para integrar 2 o inclusive mas motores escritos en diferentes lenguajes de programacion:
			Application
			    │
			    v
			ICalculationEngine
			    │
			    ├── JavaCalculationEngine
			    │
			    └── RCalculationEngine

		- Java: orquestación, importación/exportación, cálculo numérico general, álgebra lineal, optimización y procesamiento paralelo.
		- R: estadística clásica y avanzada, inferencia, econometría, bioestadística y generación de modelos ampliamente validados por la comunidad científica.
		- Python (opcional): aprendizaje profundo, inteligencia artificial moderna y acceso a ecosistemas como PyTorch, TensorFlow o scikit-learn, (posible incorporación futura).
